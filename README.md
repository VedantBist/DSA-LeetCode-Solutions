# DSA LeetCode Solutions

This repository contains Java solutions for LeetCode problems and practice from the Striver A2Z DSA Sheet. Solutions are organized by the primary algorithmic pattern used to solve each problem, rather than by difficulty.

Each solution remains in its own Java file and follows the format expected by LeetCode. Empty pattern folders are kept in place so the structure can grow with future practice.
