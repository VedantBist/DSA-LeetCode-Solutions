 # DSA LeetCode Solutions

This repository contains solutions to LeetCode problems that I have solved using Java. It serves as a collection of my practice, learning, and progress in data structures and algorithms.

## Organization

Solutions are organized into directories based on their LeetCode difficulty:

```text
Easy/
  Solutions rated Easy
Medium/
  Solutions rated Medium
Hard/
  Solutions rated Hard
```

Each solution is stored in its own Java file and follows the format expected by LeetCode.
